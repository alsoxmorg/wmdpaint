wmdpaint development guide
=========================

Keep the editor small, fast, and simple. Prefer direct functions, existing
SDL facilities, and compile-time settings over frameworks and new dependencies.

Build and configuration
-----------------------
make builds src/wmdpaint.c as one C99 translation unit. Nuklear, stb, fonts,
and icon/logo headers are checked in. SDL3 is the default; src/sdl_wmd.h keeps
an SDL2 compatibility path. src/config.h controls the platform/renderer;
src/config_paint.h controls paint features. Rebuild after configuration edits.
Do not modify vendor headers to change application behavior.

Source map
----------
src/wmdpaint.c: application state, events, UI, tools, selections, document I/O,
               transform callbacks, undo/redo, texture lifecycle.
src/layer.h:   independent RGBA16 buffers, offsets/properties, blend modes.
src/canvas_render.h: clipped CPU compositing and RGBA16-to-RGBA8 conversion.
src/farbfeld.h: native-endian FFImage plus standard big-endian farbfeld I/O.
src/1fpirate.h: packed monochrome I/O and Floyd-Steinberg export.
src/wmdarchive.h: restricted tar archives and optional bzip2 compression.
src/filebrowser.h, src/create.h: immediate-mode file and canvas dialogs.

Pixels and rendering
--------------------
Tools edit Layer.px (native-endian uint16_t RGBA). canvas_composite combines
layers into FFImage.px, converts to RGBA8, and uploads the dirty texture region.
Normal blending has transparent/opaque shortcuts; other modes use the generic
blend path. Dirty strokes avoid whole-document work. Interpolated colour
strokes batch compositing; monochrome preserves per-stamp dither semantics.
paint_selected checks canvas-coordinate mask coverage at every painting
destination, translating layer-local coordinates with the layer origin. Fill
checks both the seed and neighbors so unselected pixels block traversal.
Built-in brushes use BRUSH_SIZE_MAX (1024); bound loops to the layer wherever
possible so large brush stamps on small layers stay cheap.
SDL renders the canvas and overlays before Nuklear renders the panels.
See doc/PERFORMANCE.md for measured scenarios and outstanding profiling work.

Undo and transforms
-------------------
Undo records cover pixels, stack order, additions/deletions, full documents,
and monochrome mode. Match the snapshot to the affected data. Full-canvas
snapshots preserve layer geometry, pixels, and properties. A new edit clears
redo. history_clear frees owned record data and resets active scale state.

Resize and Move > Scale share corner hit testing and default-on aspect lock.
The original raster is retained for preview; the opposite corner is fixed.
Nearest/Smooth sampling is shared by layer drags, numeric layer resize, and
canvas scaling. SCALE_SIZE_MAX is 65535; canvas scaling prepares every new
raster before committing so allocation failure leaves the document intact.
Nearest maps destination pixel centres and copies RGBA16;
Smooth retains bilinear interpolation. Sampling changes invalidate previews.
Snapshot only on a successful changed preview. Release applies final pointer
coordinates and optional canvas expansion; Escape cancels the transaction.
Changing the active layer must not redirect a pixel undo to the wrong layer.

Files
-----
Farbfeld must remain the standard 8-byte magic, BE32 dimensions, BE16 RGBA
format. Guard dimensions and allocation arithmetic without altering wire data.
1fpirate stores MSB-first padded rows and has no alpha channel. Check header,
payload, and close errors; a buffered close can fail after successful writes.

Normal Save/Save As support layered .wmd/.wmd.bz2 paths as well as flattened
image paths. The explicit Make Layered Archive command remains available.
See doc/PROJECT_FORMAT.md. Never mark the document clean on a failed save.

Checks
------
make test: archive validation, exact format bytes and malformed input,
           scalar blend/dirty rendering, real strokes, layer resize handles,
           crop/canvas sizing and document history. SDL callback tests run
           on a software renderer without opening a display.
make check-config: build with COWARD_MODE=1 and NOTTF=1 (cleans between builds).
make ui-test: Xvfb startup smoke check; skips when Xvfb is unavailable.
make bench: optimized render benchmark; use ./tests/bench_canvas mixed too.

Update README.md, doc/wmdpaint.md, and wmdpaint.1 when behavior changes.
Keep doc/wmdpaint.1 identical to the root manual. doc/CLAUDE.md contains concise
contributor conventions. TODO.txt tracks priorities, not already present tools.
